# Service Lists

## 🌐 [Открыть Service Lists](https://dkhnv.github.io/Service-Lists/)

Я собрал в одном месте списки IP-сетей и доменов для сервисов, которые часто приходится учитывать отдельно в сети. Вместо того чтобы открывать несколько репозиториев и искать нужный файл вручную, можно просто открыть сайт, выбрать сервис и посмотреть нужный список.

Сейчас доступны списки для:

- YouTube
- Telegram
- Meta
- ChatGPT
- Discord
- Netflix
- Services

Для каждого сервиса есть три варианта списка:

- **CIDR** — IPv4-адреса и подсети, по одной записи в строке.
- **RouterOS** — те же сети в готовом формате address-list для RouterOS.
- **DNS** — доменные имена, связанные с сервисом.

На странице сервиса список можно посмотреть прямо в браузере, скопировать, скачать файлом или открыть его Raw-версию на GitHub.

## Откуда берутся данные

У каждого сервиса есть свой отдельный GitHub-репозиторий с исходными списками. Service Lists просто собирает их в одном удобном интерфейсе и показывает актуальное содержимое этих файлов.

Если исходный список в репозитории обновился, новые данные появятся на сайте при следующем открытии или обновлении страницы. Ничего отдельно синхронизировать не нужно.

## Зачем этот репозиторий

В этом репозитории находится только сам сайт Service Lists: его страницы, оформление и список подключённых сервисов. Сами IP-адреса, сети и домены по-прежнему хранятся в отдельных репозиториях соответствующих сервисов.

Если вам нужны только готовые списки, проще сразу пользоваться сайтом:
