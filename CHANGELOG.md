# Changelog

## 1.0.0

- Первый публичный релиз Service Lists.
- GitHub Dark UI в стиле Service Router.
- Семь сервисов: YouTube, Telegram, Meta, ChatGPT, Discord, Netflix, Services.
- Три представления на сервис: CIDR, RouterOS, DNS.
- Статистика количества записей.
- Дата последнего push исходного репозитория с 15-минутным browser cache.
- Fallback даты из заголовка `#Gen... DD.MM.YYYY`, если GitHub API временно недоступен.
- Просмотр Raw и локальное скачивание отображаемого файла.
- Без backend, Jekyll, Python runtime, npm и внешних UI-библиотек.
- GitHub Pages deployment через GitHub Actions.
