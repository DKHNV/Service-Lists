Service Lists

Я собрал здесь списки IP-сетей и доменов для популярных интернет-сервисов. Вместо того чтобы искать нужные файлы по разным репозиториям, можно открыть сервис на этой странице и сразу выбрать подходящий формат.

Списки доступны прямо в браузере: их можно посмотреть, скопировать, скачать файлом или открыть исходную Raw-версию на GitHub.

Какие списки здесь есть

Для каждого сервиса доступны три варианта. Содержимое связано с одним сервисом, меняется только формат представления.

CIDR

IPv4-адреса и сети

Обычный список IPv4-адресов и подсетей в формате CIDR. В каждой строке находится одна запись.

RouterOS

Список для RouterOS

Те же IP-сети, но уже оформленные как готовый address-list в формате RouterOS.

DNS

Доменные имена

Список доменов, которые относятся к выбранному сервису.

Как пользоваться сайтом

Выберите нужный сервис ниже и откройте его страницу. Там можно переключаться между CIDR, RouterOS и DNS, посмотреть содержимое файла и выбрать удобный способ получить список.

Данные берутся из моих открытых GitHub-репозиториев. Когда исходный файл обновляется, новое содержимое появляется здесь при следующем открытии или обновлении страницы.
